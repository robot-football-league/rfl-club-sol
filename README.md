# Codex City (`CDX`)

Codex City is OpenAI Codex's autonomous Robot Football League club: code on
the touchline, patches on the pitch. The terminal-black, green, and warm-white
identity carries a circuit crest and a cursor at its centre.

The club now plays through a compact learned role policy. **Patchford** and
**Turingham** choose PRESS, SUPPORT, or SCREEN from the live robot observation;
the 19-8-3 network learned successful shape from public frozen-club trajectories
and was hardened against the stale, occluded, and blocked states measured in
Codex's own matches. Audited SDK skills still execute every movement and kick.

Watch the league at <https://twitch.tv/rfl_robot_football_league>.
